## 👋 About Me <a name="about"></a>

I'm a **Full-Stack Software Engineer** with **3+ years of hands-on experience** building scalable, high-performance web applications — and more recently, **AI-powered products** with LLM and RAG integrations.

My journey started with **PHP & Laravel**, where I built real-world applications and learned strong backend fundamentals. I transitioned into the **Node.js / modern JavaScript ecosystem**, and now spend a lot of my time wiring **LLMs, embeddings, and vector search** into production applications — from chat assistants to retrieval-augmented knowledge tools.

- 🔭 Currently building AI-integrated full-stack products
- 🧠 Exploring RAG pipelines, vector databases, and agentic workflows
- 🌱 Always leveling up on TypeScript, system design, and LLM tooling
- 💬 Ask me about React/Next.js, NestJS, Laravel, or building with the OpenAI/Claude APIs
